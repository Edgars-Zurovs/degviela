# Топливо LV

Личное приложение (для себя и друзей): где в Латвии выгоднее заправиться. Работает на Android и iPhone как обычное приложение (PWA), без регистрации и без своего сервера.

## Как это устроено

- **Сборщик** (`collector/`) по расписанию читает официальные страницы цен Circle K и Virši (с соблюдением `robots.txt`), берёт список заправок из OpenStreetMap и пишет `web/data/offers.json`.
- **Запускает его GitHub Actions** (бесплатно, каждые 3 часа). Свой сервер или ноутбук не нужны.
- **Приложение** (`web/`) публикуется на GitHub Pages. При каждом открытии оно заново скачивает `offers.json`.

## Запуск (один раз, ~10 минут)

1. Создайте аккаунт на github.com (если нет) и новый репозиторий, например `degviela` (публичный — тогда Pages и Actions бесплатны).
2. Загрузите в него все файлы из этой папки (кнопка *Add file → Upload files*; папку `.github` тоже — если браузер её не берёт, создайте файл `.github/workflows/collect.yml` вручную и вставьте содержимое).
3. *Settings → Pages → Source: GitHub Actions*.
4. *Settings → Secrets and variables → Actions → New repository secret*: имя `CONTACT`, значение — ваша почта. Она попадает в User-Agent запросов, чтобы владельцы сайтов знали, к кому обратиться.
5. *Actions → «Сбор цен и публикация» → Run workflow*. Через 2–3 минуты адрес приложения будет в *Settings → Pages* (вида `https://<имя>.github.io/degviela/`).
6. Откройте адрес на телефоне: Android (Chrome) — меню → «Установить приложение»; iPhone (Safari) — «Поделиться» → «На экран Домой».

Если первый запуск упал — откройте его лог в *Actions*: в нём видно, какую сеть не удалось прочитать и почему.

## Что важно знать

- Сети обновляют цены на сайтах примерно **раз в сутки** (Virši — не по выходным и праздникам). Чаще проверять смысла нет: показанная цена — это **цена сети на момент её публикации**, а не данные с табло.
- Circle K публикует минимум только по **Риге**, Viada — по **Риге и Лиепае**, Virši — по **Риге и окрестностям**. Другие города получают цены только на газ (единая цена сети).
- Сети публикуют **минимальную** цену и адреса, где она действует. У таких станций цена точная («по данным сети для этой станции»); у остальных станций города показан минимум сети с пометкой, что здесь может быть выше. Флажок «только цены, привязанные к станции» скрывает вторые.
- «Цена изменилась N назад» — момент, когда **наш сборщик** заметил смену. Если смены ещё не было, показана дата сети.
- Viada подключена (цены по Риге и Лиепае). Neste, KOOL, Astarte, Straujupīte не подключены: на их сайтах нет страницы с ценами (Neste прямо отправляет смотреть цены на станции).
- Скидка карты лояльности вводится вручную в ⚙ (центы с литра).
- GitHub отключает расписание в публичном репозитории, если 60 дней не было активности. Если цены перестали обновляться — нажмите Run workflow.
- Пригородные заправки без адреса в OpenStreetMap относятся к ближайшему городу из списка (`collector/geo.py`). Ошибку можно поправить в `city_overrides.json`: `{"n123456": "Mārupe"}` (id станции виден в `web/data/offers.json`).

## Как добавить сеть

Напишите в `collector/parsers.py` функцию `parse_<сеть>(text)`, возвращающую `ParseResult`, добавьте сеть в `SOURCES` (`collector/collector.py`) и тест с примером текста страницы.

## Проверка

```
python -m unittest discover -s collector/tests -t .
node web/tests.js
```

Файл `web/data/offers.json` из архива — **демонстрационный** (вымышленные цены и координаты). Он заменяется при первом запуске сборщика.
